# Agent 证据覆盖实验记录

## 复算方式

在仓库根目录执行以下命令，将 `RUN_DIR` 换成要分析的 Agent 结果目录。脚本读取该目录的 `merged.json`、冻结题集与图像清单，以及生成问答结果的 `agent_trace`，无需启动模型。

```bash
RUN_DIR=output/agent/a100_4gpu_tp1_status_c4_mm3

# 详细统计，包含单双页分组、部分分、零分和搜索诊断
../.venv_grpo/bin/python -B -m evaluations.agent.analyze_evidence_coverage "$RUN_DIR"

# 生成一行 Markdown，把新实验的输出粘贴到下表末尾
../.venv_grpo/bin/python -B -m evaluations.agent.analyze_evidence_coverage "$RUN_DIR" --markdown-row
```

## 统计口径

- 只纳入标准答案可答、且有有效证据页标注的题。用冻结题集取标注，将数据集的 1-based 页号减一，与冻结图像清单中的物理页号比对。空标注或有任一标注页超出范围的题单列。
- `读全` 统计成功 `read_page` 读取过的页面，允许分多轮完成。`存全` 统计成功 `store` 进入 memory 的页面。
- `带全请求` 以实际 Reasoner 请求携带的整页图为准。`最终满分` 要求该题曾带全标注页请求 Reasoner，且最终官方逐题 `score = 1`。
- 每个阶段先显示覆盖题数占有效标注题的比例。分号后的比例以上一阶段通过的题数为分母。`读全` 的两个分母相同，仅显示一次。
